# نظام بوصلة لجرد الأصول الثابتة

نظام ويب لإدارة وجرد الأصول الثابتة للشركات، مبني على ربط كل أصل بموقعه الجغرافي (GPS) لتسهيل عملية الجرد الميداني.

## المميزات
- مشروع مستقل لكل شركة عميلة بمواقعها (مقر / فروع / مخازن) معروضة على خريطة تفاعلية بإحداثيات GPS
- كل أصل مربوط بموقعه: الفرع + الدور + الغرفة، مع إمكانية التقاط إحداثياته من الموبايل أثناء تركيب التاج المعدني
- جرد سريع بمسح كود التاج (QR) أو إدخال الكود يدوياً، مع تتبع لحظي للتقدم في كل موقع
- حالات واضحة لكل أصل: لم يتم / تم الجرد / غير موجود (فروقات)
- لوحة مؤشرات: إجمالي الأصول، ما تم جرده، المتبقي، والفروقات
- إضافة أصول جديدة من الميدان مباشرة

## التشغيل
افتح `index.html` في أي متصفح حديث — لا يحتاج خادماً. النسخة الحالية تجريبية وتعمل ببيانات وهمية محفوظة محلياً في المتصفح.
